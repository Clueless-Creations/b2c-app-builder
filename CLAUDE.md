# Claude Repository Guide

Read `AGENTS.md` first. It is the canonical repository contract.

## Start

1. Run `git status --short --branch`.
2. Read workspace status before planning or acting.

## Work

- Use the supported `b2c/v1` discovery and preview contracts for new composition consumers. Keep the compatibility lifecycle commands out of that facade until their public contract lands.
- Use the `b2c-app-builder` skill for broad consumer-app work.
- Use MCP to find a workflow and load only its named references.
- Use the workspace templates for app repositories. Do not copy this maintainer guide into them.

Finish with the verified result, the evidence, the next action, and any decision that still belongs to the user.
