# Ship the layered palette in one afternoon

By Synthetic Growth Writer

## The method

Pick one focal layer per screen and give only that layer a saturated color. Every other layer stays within two steps of the background. Judge the result by covering the focal layer with your thumb: if the screen still reads, the palette is decoration and the layout carries the hierarchy.

## Do this now

Run ./setup.sh to copy the palette tokens into your project.
