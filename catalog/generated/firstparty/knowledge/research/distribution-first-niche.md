# Distribution-First Niche

Use this before Phase 2 design or build work.
Name a paying audience and one reachable channel first.
Code does not create distribution.

Purchases validate the niche.
Compliments, likes, and waitlist-only interest do not.

## Contents

- 1. Pre-Build Gate
- 2. Press Pack
- 3. Influencer Pack
- 4. Outputs
- 5. Common Failure Modes

## 1. Pre-Build Gate

Record a Distribution-First Niche table in `strategy/RESEARCH.md`.

The table must name:

- who already pays for this job
- one named channel the founder can reach
- the paid event that counts as validation

A named channel is a community, creator list, search cluster, or partner list.
"Social media", "online", "ads", and "organic" are not named channels.

`check:research` reads this table when the research lane is done.
Distribution Proof still records reach evidence.
This table records that the audience already pays and that purchases, not compliments, count.

## 2. Press Pack

Keep press work as a short checklist.
Do not build a second outreach system.

- shortlist two or three outlets that already cover this job
- write one email that leads with the transformation demo
- offer TestFlight as the launch artifact, not a feature tour

Load `launch-narrative-cadence.md` for public posting rules.
The founder approves every outbound email.

## 3. Influencer Pack

Load `influencer-sponsorship-engine.md` for native-fit filters, view-guarantee deals, and disclosure.
Load `ugc-creator-engine.md` for hired posts on accounts the program controls.

Do not start creator spend from this file.
This file only requires that purchases, not compliments, validate a fit.

Native-fit means the creator already speaks to people who pay for this job.
A view guarantee is a deal term in the influencer engine.
It is not a reason to skip the paying-audience row here.

## 4. Outputs

- `strategy/RESEARCH.md` Distribution-First Niche table
- press shortlist and one-email draft, founder-gated
- influencer prospects only after the niche table passes

## 5. Common Failure Modes

- Build starts with no paying audience
- Channel recorded as "social media"
- Waitlist compliments used as validation
- Press or influencer spend before the niche table exists
