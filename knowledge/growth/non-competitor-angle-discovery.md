# Non-Competitor Angle Discovery

Use this before the first paid creative batch.
Direct competitor ads are a trap when every angle is a logo swap of the same category tropes.
Fresh angles come from four hunt sources, then from the same customer with a new motivation.

Load `paid-user-acquisition.md` for channel, cadence, and kill rules.
Load `../design/design-worthiness.md` for the logo-swap originality rule.

## 1. Four Hunt Sources

Record a Non-Competitor Angle Hunt table in `growth/PAID_UA.md`.

Hunt these source kinds before spend:

- print — slogans, layouts, and frames from print, not from in-category ads
- cross-niche — a psychological trigger from a different market
- ad-library-adjacent — public ad libraries for the same targeting or an adjacent or international category, not the direct incumbent
- second-profile — a second motivation for the same ideal customer

The hunt must name all four kinds.
Not every hunted angle must ship.
At least one adopted angle must come from a non-competitor source.

Do not start with a paid bookmark tool when these four sources can run.

## 2. Same Customer, New Motivation

When the primary profile saturates, expand motivations for the same customer.
Do not only raise budget.
Do not switch to a new customer until the current customer has a second truthful motivation.

Record that expansion in the hunt table.
The product must still serve the new motivation.

## 3. Competitor-Wrong Gate

Each adopted angle records a competitor-wrong result:

- `original` — a logo swap onto a category competitor would not still work
- `logo-swap` — the angle still works if you only change the wordmark

At least one adopted angle must be `original`.
A batch of only `logo-swap` angles is not ready for first spend.

This is the paid-creative bind of design-worthiness originality.
Do not invent a beauty score.

## 4. Ethics And Vendors

Adapt the trigger.
Never clone competitor assets, footage, or claims.
Never add fake scarcity.

Foreplay and similar bookmark tools are optional.
They are not a B2C App Builder default.

## 5. Outputs

- Non-Competitor Angle Hunt table in `growth/PAID_UA.md`
- angle IDs in `CONTENT_ASSETS.md` that cite hunt rows
- one adopted `original` angle before first spend
- same-ICP new-motivation row after primary saturation

## 6. Common Failure Modes

- First creative batch mined only from direct competitor ads
- Raising budget when the primary motivation is exhausted
- Adopted angles that all pass a logo-swap onto a category rival
- Cloning competitor claims or creatives
