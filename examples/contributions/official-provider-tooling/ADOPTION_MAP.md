# Official provider tooling adoption

This is a real, source-reviewed contribution proposal. It does not certify installed tools or live provider behavior. The contribution manifest owns exact source identities, selected paths, rights, derivations and evaluation routes.

RevenueCat AI toolkit and CLI inform the existing RevenueCat integration owner through a focused guide. The CLI executable relationship wraps a trusted host `rc`/`revenuecat` binary for selected typed operations at release v0.1.1. It does not add a second upstream identity, install the binary, or treat the later source head as the installed release. PostHog wizard informs measurement setup and disclosure review through a separate guide. Their original MIT notices travel with the adapted resources. The RevenueCat identity skill conflict is deliberately resolved using official customer documentation, not silently copied.

PostHog context mill remains deferred. Its reviewed revision had no root license. No content from that repository or its generated skill bundles is shipped. Tracking a project is distinct from claiming it powers the product.

Proposed units must pass source-specific acceptance checks before promotion. The tests use an accepted copy of this manifest to prove the boundary without changing the proposal or connecting any business.
