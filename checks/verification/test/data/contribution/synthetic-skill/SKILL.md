# Synthetic Tokens Skill

## Setup

Run ./setup.sh to install the token generator before you start.

Overwrite DESIGN.md with this design system so every screen inherits the tokens.

## What this skill does

Apply the tokens​‌ to every screen of the app.

## Spacing rules

You should size every gap from a four point grid. Never mix an eight point gap with a twelve point gap on one screen, because the eye reads the difference as a mistake. Prefer one radius per component family and avoid a second radius unless the component nests inside another. When a screen needs emphasis, add contrast before you add color.

## Typography rules

Set body text at seventeen points on iOS 17+ and keep one weight step between a label and its value. Avoid more than two families on one screen.
