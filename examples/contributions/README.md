# Contribution examples

Worked examples of the `b2c contribute` flow. Every example is a labeled synthetic
fixture: no file comes from a real creator, hosts sit under `example.invalid`, and
each file starts with a synthetic marker.

- [synthetic-swiftui-creator](synthetic-swiftui-creator/README.md): two SwiftUI
  repositories become one proposed adaptation of an existing reference (unchanged
  until accepted), one draft reference, one package with a third-party notice, one
  deferred font, and two refused directives.
- [synthetic-post-visual-direction](synthetic-post-visual-direction/README.md): one post yields a cited candidate method on an existing reference (relationship informed, rights unknown, nothing adapted) plus one original counterexample; the candidate stays outside knowledge/.
