# Transformation Demo

Use this before a consumer-app Go verdict.
The product must show one before-to-after change in one screenshot and a 15-second script.

This gate is the research-phase check.
It does not replace the five-second demo moment in `influencer-sponsorship-engine.md`.
Creatives and onboarding reuse this same asset later.

## Contents

- 1. Required Outcome
- 2. Vitamin Rejection
- 3. Shared Asset
- 4. Outputs
- 5. Common Failure Modes

## 1. Required Outcome

Record a Transformation Demo table in `strategy/RESEARCH.md`.

The table must name:

- one screenshot path
- one 15-second spoken or on-screen script
- the transformation the user sees
- why the change is a painkiller, not a vitamin

The screenshot path must be a real relative file path.
The script must describe one action and one result.
The transformation must name a before state and an after state.

`check:research` reads this table when the research lane is done.
A missing column or a vitamin transformation fails the gate.

## 2. Vitamin Rejection

A vitamin feature improves a vague good.
It does not remove a concrete pain.

Reject rows that rest on wellness, generic productivity, or "feel better" language in the transformation cell.
A painkiller restores a lost result, removes a block, or finishes a job the user already pays to solve.

Durable patterns, not clone recipes:

- recover a broken streak
- show the next action after a miss
- turn a raw capture into a judged result

Do not copy another app's UI.
Do not treat a mood or a lifestyle claim as the demo.

## 3. Shared Asset

The same screenshot and script feed paid creative and onboarding later.
Do not invent a second demo for ads.
Do not invent a second demo for the first-value screen.

## 4. Outputs

- `strategy/RESEARCH.md` Transformation Demo table
- screenshot file under a proofs path
- later reuse in `PAID_UA.md` creative and `product/ONBOARDING.md` first value

## 5. Common Failure Modes

- Vitamin copy in the transformation cell
- A screenshot path with no slash and no image suffix
- A script too short to be spoken in 15 seconds
- A new demo invented later for ads
