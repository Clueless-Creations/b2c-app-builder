# Kill the gradient, then re-test

By Synthetic Designer

I review a lot of app screens. Most of them lean on color to fake a hierarchy that the layout never earned. The gradient hero, the tinted card, the accent border: they all promise structure and deliver mood.

My test takes one step. If a screen's hierarchy survives grayscale, the palette is doing decoration, not information. Kill the gradient and re-test. If the screen still reads in the same order, the color was ornament. If the order collapses, color was carrying meaning that type, spacing, and contrast should have carried.

How I run it:

1. Export the screen as it ships.
2. Convert it to grayscale. Leave the levels alone.
3. Ask someone who has never seen it: what do you look at first, second, third?
4. Remove the gradient and every tinted fill. Ask the same question again.

When the two answers match, ship the flat version and give the palette a real job.

This one got 10k likes last week, so I guess it struck a nerve.

We tried it on our own onboarding. We saw +4% completion after we killed the gradient. Take that for what it is.
