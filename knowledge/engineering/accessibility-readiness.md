# Accessibility Readiness

## Purpose

Use this guide to prove that customers can complete the common tasks of the app.

## Required proof

1. List the common tasks and the supported device classes.
2. Test each task with VoiceOver or TalkBack.
3. Test large text, contrast, reduced motion, and alternative input where the platform supports it.
4. Record the build, device, operating system, result, defect, owner, and evidence.
5. Reconcile the results with the App Store accessibility declarations.

Static analysis does not replace common-task testing. An untested common task is a release blocker.

## Output

Write the results in `engineering/ACCESSIBILITY_READINESS.md`.
