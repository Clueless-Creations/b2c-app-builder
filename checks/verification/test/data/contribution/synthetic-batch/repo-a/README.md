# Card Stack Method

## Stacking rules

A stack should show at most three cards, because a fourth card reads as clutter. Never animate the back card; prefer a static shadow and avoid parallax when the device reduces motion. When a card leaves the stack, the next card must settle before input resumes.

## Gesture thresholds

Swipe commitment starts at forty percent of the card width. Below that, the card must return to rest.
