# A palette test for visual direction

By Synthetic Designer

## Grayscale first, then the palette

I review app screens for a living, and most of them lean on color to fake a hierarchy that the layout never earned. My test is short. Convert the screen to grayscale. If the reading order survives, the palette is decoration and you should keep it out of the argument. If the order collapses, color was carrying meaning that type, spacing, and contrast must carry instead.

## Why audience facts beat generic templates

Never start from a template palette, because a template knows nothing about the people who open the app. Prefer a palette derived from audience facts: what they wear, where they read, which brands they already trust. Avoid the indigo gradient hero; it is the generic tell that says nobody decided anything.

## When the test breaks

The test fails on a data-dense dashboard, where a monochrome screen hides which number matters. When the screen is a dashboard, judge the color system on its own terms and do not apply the grayscale rule.
