selected paths, units, derivations, notice coverage and evaluation routes. The
repository's upstream manifests own ongoing maintenance. No source script was run.

The shared capture recipe has several upstream sources but remains one maintained
reference. No top-level skill or knowledge hierarchy was created for each author.
The EmergeTools repository address is mapped to the canonical SnapshotPreviews
identity, with original author credit intact.

The contribution check validates exact commits, source mappings, derivations and
matching retained notices. The fixture suite additionally exercises the active
knowledge routes, packaged notice coverage and generated maintainer gap report.
Provenance and a passing fixture are not proof that a real editor export or device
run succeeded. Use the accepted screenshot and runtime evidence contracts for that.

```sh
b2c contribute check --target examples/contributions/screenshot-toolchain --json
npm run test:fixtures -- screenshot-upstreams
npm run check:upstreams
npm run check:credits
```

Review source changes through upstream-check and upgrade-plan before updating
these records. Preserve intentional deviations. Do not auto-install a new binary,
copy an upstream skill into discovery paths or repin an existing business.
